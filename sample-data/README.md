# Sample data (synthetic)

Two fictional clients, each in its own folder so they are never loaded together. The files
imitate the layout of real exports closely enough to test Readout, but they are not copies of
real files, and real exports may differ.

| Folder | Story | Generated by |
|---|---|---|
| `northwind-bakery/` | Traffic **drops** | `tools/make_sample_data.py` |
| `lakeview-plumbing/` | Traffic **gains** | `tools/make_sample_data_gain.py` |

Each folder holds the same kinds of files:

| File | Imitates |
|---|---|
| `ga4_daily_channels.csv` | GA4 Free form exploration export (Date, channel, source / medium) |
| `google_ads_campaigns_daily.csv` | Google Ads campaign report segmented by day, with title and totals rows |
| `gsc_last_16_months.zip` | Search Console Performance export, 16 months |
| `gsc_current_28_days.zip` | Search Console export for the current 28 days |
| `gsc_previous_28_days.zip` | Search Console export for the 28 days before |
| `events.csv` | An event log a consultant would keep |

## Northwind Bakery: a drop

- From 2026-10-06, three sourdough blog posts drop from about position 4 to about position 7.
- On 2026-10-05, the event log records a site redesign with a new blog template.
- Google's September 2026 spam update ran from 2026-09-24 to 2026-10-08.
- On 2026-10-12, GA4 tracking breaks for one day.
- Branded searches stay roughly flat.

## Lakeview Plumbing: a gain

- On 2026-10-15, the event log records a refresh of the water heater service pages.
- From 2026-10-20, those pages climb from about position 9 to about position 4.
- On 2026-10-27, the "Brand - Search" Ads campaign is paused, so it stops getting clicks.
- 2026-11-02 is missing from the GA4 export.
- Frozen pipe searches rise with winter, and chatgpt.com referrals grow slowly through 2026.
- It also includes awkward values: queries with commas, quotes and accents, `(not set)` and
  `Unassigned` rows, a non-empty Search appearance table, and several Ads total rows.
