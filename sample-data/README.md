# Sample data (synthetic)

Fictional exports for "Northwind Bakery", generated by `tools/make_sample_data.py`.
They imitate the layout of real exports closely enough to test Readout, but they are not
copies of real files, and real exports may differ.

| File | Imitates |
|---|---|
| `ga4_daily_channels.csv` | GA4 Free form exploration export (Date, channel, source / medium) |
| `google_ads_campaigns_daily.csv` | Google Ads campaign report segmented by day, with title and totals rows |
| `gsc_last_16_months.zip` | Search Console Performance export, 16 months |
| `gsc_current_28_days.zip` | Search Console export, 2026-09-28 to 2026-10-25 |
| `gsc_previous_28_days.zip` | Search Console export, 2026-08-31 to 2026-09-27 |
| `events.csv` | An event log a consultant would keep |

The story in the data:

- From 2026-10-06, three sourdough blog posts drop from about position 4 to about position 7.
- On 2026-10-05, the event log records a site redesign with a new blog template.
- Google's September 2026 spam update ran from 2026-09-24 to 2026-10-08.
- On 2026-10-12, GA4 tracking breaks for one day.
- Branded searches stay roughly flat.
